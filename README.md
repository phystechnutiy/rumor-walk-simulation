# Rumor Walk Simulation

## Идея проекта

Проект реализует компьютерную модель распространения слухов в обществе, используя аналогию со случайными блужданиями из термодинамики. Слух распространяется через мобильных агентов, которые перемещаются по графу социальной сети и передают информацию при контактах. Модель опирается на классические подходы Maki-Thompson и Daley-Kendall, расширенные идеей infectious random walks.

Цель: показать связь между термодинамическими случайными блужданиями и динамикой информации в социальных сетях, исследовать влияние топологии графа на скорость распространения.

## Архитектура

| Модуль | Описание |
|---|---|
| `Agent` | Человек с одним из трёх статусов: ignorant / spreader / stifler |
| `Graph` | Граф социальной сети, по которому перемещаются агенты |
| `InteractionModel` | Правила взаимодействия агентов по модели Maki-Thompson |
| `Simulator` | Основной движок симуляции с поддержкой Monte-Carlo |
| `PhaseAnalyzer` | Анализ фазовых переходов и критических значений λ |

### Состояния агента

```
ignorant  →  spreader  →  stifler
   (λ)                      (α)
```

- **ignorant** — не знает слух
- **spreader** — активно распространяет слух
- **stifler** — знает слух, но больше не распространяет

### Параметры модели

| Параметр | Описание |
|---|---|
| `λ` (lambda) | Вероятность, что spreader заразит ignorant |
| `α` (alpha) | Вероятность, что spreader станет stifler |
| `n` | Количество агентов и узлов графа |
| `p` | Вероятность ребра в графе Эрдёша-Реньи |

## Фичи

- Многопоточная симуляция через `ProcessPoolExecutor` с методом Monte-Carlo
- `PhaseAnalyzer` — поиск критического значения λ_c, при котором рост spreader'ов максимален
- Граф Эрдёша-Реньи (`ErdosRenyiGraph`) с настраиваемой вероятностью рёбер
- Воспроизводимые результаты через seed генератора случайных чисел

## Как запустить

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск

```bash
python main.py
```

Вызов нужной функции настраивается внутри `main()` в `main.py`.

### Доступные режимы

**Monte-Carlo симуляция** — запускает `n_runs` независимых прогонов и печатает историю состояний агентов по шагам:

```python
def main():
    _monte_carlo()
```

**Поиск критических λ** — перебирает значения λ от `lambda_start` с шагом `lambda_step` для каждого размера сети из `sizes`, находит λ_c при котором рост spreader'ов максимален:

```python
def main():
    _critical_lambdas()
```

**Поиск точек перегиба** — то же, но ищет λ по точке перегиба кривой распространения:

```python
def main():
    _inflection_points()
```

### Параметры

**`build_simulator(n)`** — создаёт экземпляр симулятора:

| Параметр | Где менять | Значение по умолчанию | Описание |
|---|---|---|---|
| `n` | аргумент функции | `3` | Количество агентов и узлов графа |
| `p` | `ErdosRenyiGraph.generate(p=...)` | `0.5` | Вероятность ребра в графе Эрдёша-Реньи |
| `_lambda` | `InteractionModel(_lambda=...)` | `0.3` | Вероятность передачи слуха |
| `_alpha` | `InteractionModel(_alpha=...)` | `0.3` | Вероятность затихания spreader'а |
| `seed` | `np.random.default_rng(seed=...)` | `0` | Seed для воспроизводимости |

**`_monte_carlo()`**:

| Параметр | Где менять | Значение по умолчанию | Описание |
|---|---|---|---|
| `n` | `build_simulator(n=...)` | `3` | Размер сети |
| `n_runs` | `sim.run_monte_carlo(n_runs=...)` | `5` | Количество прогонов |

**`init_phase_analyzer()`** — настройка `PhaseAnalyzer` для обоих режимов анализа:

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| `lambda_start` | `0.1` | Начальное значение λ при переборе |
| `lambda_step` | `0.1` | Шаг перебора λ |
| `sizes` | `[10, 50]` | Размеры сетей для анализа |
| `n_runs` | `10` | Число Monte-Carlo прогонов на точку |
