# Название проекта

## Идея проекта
Проект реализует компьютерную модель распространения слухов в обществе, используя аналогию со случайными блужданиями из термодинамики. Слух распространяется через мобильных агентов, которые перемещаются по графу социальной сети и передают информацию при контактах. Модель опирается на классические подходы Maki-Thompson и Daley-Kendall, расширенные идеей infectious random walks.

Цель: показать связь между термодинамическими случайными блужданиями и динамикой информации в социальных сетях, исследовать влияние топологии графа на скорость распространения.

## Архитектура
Agent - человек, который может иметь один из трех статусов (неосведомленный, переносчик, забывший)
Graph - граф, по которому перемещаются люди
InteractionModel - модель взаимодействия агентов, которая меняет их статусы по специальным правилам модели Maki-Thompson
Simulator - движок, в котором происходят основные вычисления 
PhaseAnalyzer - модуль, позволяющий анализировать результат моделирования (вычисление критических значений вероятностей взаимодействия) 

## Фичи 
Реализована возможность запускать многопоточную симуляцию с использованиями методов Monte-Carlo через `ProcessPoolExecutor`. Помимо этого, добавлен `PhaseAnalyzer`, который позволяет находить предельные значения констант, при которых рост количества `spreader'ов` максимален, а также минимально возможные значения констант. 

## Как запустить
### Установка зависимостей
```bash
pip install -r requirements.txt
```
### Запуск базовой симуляции 
```bash
python main.py
```
Параметры симуляции (n, lambda, alpha, n_runs) 
настраиваются в main.py
